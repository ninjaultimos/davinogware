# DaviNogware

Site de apresentação da DaviNogware: sites para todos os negócios, feitos para o celular, com pedido e agendamento pelo WhatsApp.

- Site: https://davinogware.vercel.app
- HTML, CSS e JS puros, sem build. A pasta raiz é publicada como está.
- Projetos no ar (área "Projetos"): pizzaria, odontologia, vidraçaria, barbearia, estética, loja, academia, marmoraria e médico, cada um com seu próprio deploy.

## Como incluir um projeto novo na área "Projetos"

1. Salve uma captura do site em `img/proj-NOME.jpg` (960×600).
2. Em `index.html`, procure `id="catalogo"`, copie um `<article class="cat">` inteiro e troque imagem, nome, texto, tags e links.
